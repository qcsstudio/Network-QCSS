# Contextual Graphics Review

## Scope

- Rebuilt 13 shared public-page scenes with recognizable network appliances, server cabinets, workstations and wireless access points.
- Assigned distinct service scenes to managed networks, security, cloud, firewall management, Wi-Fi, monitoring, troubleshooting and authorized testing.
- Reworked homepage hardware, engineering stages, deliverable records, packet journey devices and diagnostic example.
- Preserved published lesson diagrams, article images, editorial generation and backend behavior.
- Illustrations describe concepts and examples, not live infrastructure, measured scores or completed customer work.

## Visual Contracts

- Every journey has a visible source and destination. The training example includes PC1, switch, router and PC2.
- Firewall-denied traffic stops before the destination. Firewall inspection alone does not imply encryption.
- The cloud example protects only gateway-to-gateway transit; local links remain unwrapped.
- Wireless radio arcs are an illustration, not a measured coverage survey.
- DNS examples use example.test and documentation-only addresses.
- Screens contain complete phrases. Supporting information remains in accessible HTML captions.
- Static fallbacks correspond to the animated scene; captured locally from the model without external asset licensing or API charges.
- Motion is lazy-loaded, paused offscreen, paused in inactive tabs, and respects reduced-motion preferences. Screen textures are disposed alongside geometry and materials.
