QCS shared homepage theme rollout - 2026-09-30

Scope
- Root-local Geist and Geist Mono fonts, QCS pink/charcoal/blue palette.
- Shared header, footer, focus states, form controls and restrained repeated cards.
- Service, solution, assessment, institute, resource and course introductions use
  the homepage Three.js renderer with topic-specific scenes and static fallbacks.
- Tools retain input-first workflows, compact introductions and existing logic.
- Blog artwork and lesson-specific technical diagrams are not replaced.
- Admin login, dashboard and client portal inherit compact operational styles.
- No authentication, publishing, research, scheduling or testing policies changed.
